# usbstream — поток самопроверки USB3 с CH569

CH569 непрерывно отдаёт в bulk EP2 IN блоки с номером и известной нагрузкой. ПК
([`sw/usbstream`](../../../sw/usbstream)) проверяет каждый блок и считает скорость. ПЛИС не нужна:
так меряется потолок USB3 → ПК, отдельно от HSPI.

Формат блока — [`stream.h`](stream.h). На USB3 блок равен одной пачке EP2, 4 пакета по 1024 байта
(4096), на USB2 — одному пакету (512). Нагрузка заполняется один раз, перед каждой пачкой
переписывается только заголовок, поэтому процессор почти не занят.

## Что откуда

| Файл | Что |
|---|---|
| `main.c` | запуск USB и светодиод статуса ([`../common/app_usb.c`](../common/app_usb.c)) |
| `ep2_stream.c` | EP2 IN через крючки [`ep2.h`](../common/ep2.h): один буфер блока, перед отправкой переписывается заголовок |
| `stream.c`, `stream.h` | формат потока |
| стек USB | общий форк BSP в [`../common/usb/`](../common/usb/) |
| `usb_cmd.c` | из подмодуля без изменений (LOGR, USBS, USB2, USB3, BOOT) |

Устройство остаётся `16c0:05dc` «HydraUSB3». Windows ставит WinUSB сама (WCID).

## Сборка и запуск

```sh
make CROSS=~/.local/opt/xpack-riscv-none-elf-gcc-12.2.0-1/bin/riscv-none-elf-   # BOARD=evt по умолчанию
make flash                                    # плата в загрузчике
make -C ../../../sw/usbstream && ../../../sw/usbstream/usbstream -t 60
```

## Замеры

| Дата | Плата | Путь | Скорость | Объём | Ошибки |
|---|---|---|---|---|---|
| 2026-10-20 | WCH CH569 EVT | USB3 SS, Windows → usbipd → WSL2, 16 × 256 КиБ | 335–345 МБ/с | 20,1 ГБ за 60 с | 0 |

Замер через USB/IP — нижняя оценка, без WSL ожидается не меньше. Пик трассы — 84 МБ/с, запас
около 4 раз. Пачка EP2 — 4 пакета (`DEF_ENDP2_*_BURST_LEVEL`). 8 или 16 могут дать больше,
но, по комментарию в BSP, на части ПК работают нестабильно.

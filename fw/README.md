# fw — прошивка CH569

Задачи прошивки:

- USB 3.0 SuperSpeed device (запасной путь — USB2 HS) с составным набором интерфейсов:
  трасса (как у ORBTrace), события, CMSIS-DAP v2, CDC-ACM, управление, DFU;
- приём пакетов из ПЛИС по HSPI (DMA, двойная буферизация) и отправка их в bulk IN;
- команды и запись CSR ПЛИС в обратную сторону;
- загрузка и обновление конфигурационного флеша ПЛИС по SPI0.

Основа — BSP и примеры [`au/hydrausb3_fw`](../au/hydrausb3_fw), протокольное ядро CMSIS-DAP —
[`au/free-dap`](../au/free-dap).

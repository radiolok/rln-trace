# sw — ПО на ПК

| Папка | Что |
|---|---|
| [`usbstream/`](usbstream/) | Приёмник потока самопроверки `fw/ch569/usbstream`: скорость, потери, порча |
| [`udev/`](udev/) | Правила доступа без root: загрузчик WCH ISP, прошивки зонда |

Утилита `rln-trace` (план):

- запись потоков трассы и событий через libusb, общий заголовок сессии;
- резка записи по интервалам PPS–PPS по номерам кадров из журнала событий;
- TCP-источник для [Orbuculum](../au/orbuculum) (опция `-s`), позже — протокол orbflow;
- подготовка снимка для [OpenCSD](../au/opencsd): кадры + ELF + конфигурация ETM;
- экспорт символизированной трассы и событий в Perfetto;
- калибровка задержек линий и управление зондом через CSR.

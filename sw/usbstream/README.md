# usbstream — приёмник потока самопроверки

Читает EP2 IN прошивки [`fw/ch569/usbstream`](../../fw/ch569/usbstream) асинхронным libusb, проверяет
каждый блок и раз в секунду печатает скорость и счётчики ошибок.

```sh
sudo apt install libusb-1.0-0-dev
make            # ./usbstream
make test       # тест разбора на синтетическом потоке, устройство не нужно
./usbstream -t 60               # 60 с, итог и код возврата
./usbstream -t 0 -o dump.bin    # до Ctrl+C, сырой поток в файл
./usbstream -C SRCI -t 10 -C STAT   # команды EP1 прошивке (hspi2usb), приём, снова команды
```

| Счётчик | Что значит |
|---|---|
| потеряно | пропущенные номера блоков |
| повторов | номер повторился или откатился |
| рестартов | номер начался с нуля посреди приёма: прошивка заново подняла USB |
| испорчено | блоки, в которых нагрузка не совпала (в скобках — число слов) |
| рассинхр. | маркер не нашёлся там, где должен начаться блок |

Код возврата: 0 — ни одной ошибки после синхронизации, 1 — ошибки или нет потока, 2 — сбой USB.
Приём может начаться посреди пачки, оставшейся с прошлого запуска. Байты до первого маркера на
границе 512 считаются пропущенными, это не ошибка.

16 передач по 256 КиБ укладываются в `usbfs_memory_mb` (по умолчанию 16 МБ на все программы).
Если больше, будет `LIBUSB_ERROR_NO_MEM`.

Проверка вынесена в [`check.c`](check.c), чтобы ей потом проверять поток с ПЛИС (PRBS через HSPI).

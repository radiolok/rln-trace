# rln-trace

**Открытый зонд Debug + Trace для ARM Cortex-M и RISC-V.**

*Open-source debug and parallel-trace probe: continuous ETM / RISC-V PIB trace over USB3,
external-event timestamps (GNSS PPS, triggers) on the same time base, CMSIS-DAP debugging.
MIPI20 target connector, VREF 1.2–3.6 V. BSD-3-Clause.*

## Зачем

Отладчик показывает, где процессор остановился. Трасса показывает, что он делал на самом деле:
каждый переход, каждое прерывание, время реакции. Открытых трассировщиков почти нет:
[ORBTrace](https://github.com/orbcode/orbtrace) не купить, а коммерческие зонды стоят очень дорого.
Для RISC-V параллельная трасса только появляется, спецификации портов и разъёмов ратифицированы недавно,
инструментов под неё мало.

rln-trace закрывает этот пробел:

- **Непрерывный поток трассы на ПК**, а не короткое окно в буфер. Цель — без потерь выдержать
  STM32F407 на 168 МГц: TRACECLK 84 МГц по обоим фронтам, 4 бита, до 84 МБ/с.
- **Метки внешних событий** (PPS от GNSS, SMA-триггеры) в той же шкале времени, что и трасса.
  Кадр трассы и событие связаны номером кадра, поэтому интервал PPS–PPS вырезается точно.
- **Отладка** через CMSIS-DAP v2: OpenOCD, pyOCD и probe-rs работают без доработок.
- **Совместимость с экосистемой:** интерфейс трассы повторяет ORBTrace, поэтому
  [Orbuculum](https://github.com/orbcode/orbuculum) работает без патчей. Декодирование — через
  [OpenCSD](https://github.com/Linaro/OpenCSD), просмотр — в Perfetto.

## Архитектура в двух словах

![Структурная схема rln-trace](hw/img/system.svg)

Работа идёт в двух направлениях с общим гейтваром и ПО:

| | A: прошивка SLogic16U3 | B: свой зонд |
|---|---|---|
| Железо | Sipeed SLogic16U3 (Gowin GW5AT, USB3 в ПЛИС) | GW2AR-18 QN88 + CH569W |
| Функции | трасса и события | трасса, события, SWD/JTAG, питание цели |
| Статус | ждём прибор, готовим boundary scan | схема rev 0.1, макет на Tang Nano 20K + CH569 |

Подробно: [hw/README.md](hw/README.md).

## Структура репозитория

| Папка | Что внутри |
|---|---|
| [`hw/`](hw/) | Аппаратура: архитектура, схемы, разводка |
| [`gw/`](gw/) | Гейтвар ПЛИС: ядра на Chisel, платформенный слой на Verilog |
| [`fw/`](fw/) | Прошивка CH569: USB3, HSPI, CMSIS-DAP |
| [`sw/`](sw/) | ПО на ПК: утилита записи, мост в Orbuculum, экспорт в OpenCSD и Perfetto |
| [`au/`](au/) | Assembly units: сторонние проекты, подключённые как git submodules |
| [`doc/`](doc/) | Документация, заметки, результаты замеров |
| [`tools/`](tools/) | Вспомогательные скрипты (генерация схемы, проверки) |

Клонирование вместе с подмодулями:

```sh
git clone --recursive https://github.com/radiolok/rln-trace
# или в уже склонированном репозитории
git submodule update --init --depth 1
```

# gw — гейтвар ПЛИС

Планируемая структура:

| Папка | Что |
|---|---|
| `cores/` | Платформонезависимые ядра на Chisel: деформатор TPIU, метки времени, пакетизатор, SWD/JTAG, CSR, мост HSPI |
| `platform/` | Платформенный слой на Verilog: примитивы Gowin (IDDR, IODELAY, PLL, SDRAM), верхние модули плат |
| `boards/` | Сборка под конкретные платы: Tang Nano 20K (макет), зонд B, SLogic16U3 |
| `test/` | ChiselSim + Verilator, тестовые векторы, записи реального потока |

Первое ядро — деформатор TPIU, описание в [`../hw/README.md`](../hw/README.md#5-плис-раскладка-и-гейтвар).
Chisel генерирует SystemVerilog через firtool; опции понижения подбираются так, чтобы результат читали
и Yosys, и Gowin EDA.

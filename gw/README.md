# gw — гейтвар ПЛИС

Планируемая структура:

| Папка | Что |
|---|---|
| `cores/` | Платформонезависимые ядра на Chisel: деформатор TPIU, метки времени, пакетизатор, SWD/JTAG, CSR, мосты к USB-чипу (HSPI для CH569, UHSIF для CH32H417) за общим интерфейсом FIFO |
| `platform/` | Платформенный слой на Verilog: примитивы Gowin (IDDR, IODELAY, PLL, SDRAM), верхние модули плат |
| `boards/` | Сборка под конкретные платы: Tang Nano 20K (макет), зонд B, SLogic16U3 |
| `test/` | ChiselSim + Verilator, тестовые векторы, записи реального потока |

Первое ядро — деформатор TPIU, описание в [`../hw/README.md`](../hw/README.md#5-плис-раскладка-и-гейтвар).
Chisel генерирует SystemVerilog через firtool; опции понижения подбираются так, чтобы результат читали
и Yosys, и Gowin EDA.

Мост к USB-чипу сменный: ядра выше него видят только потоки (трасса, события, ответы, команды) с
готовностью и признаком конца пакета. Под ними — HSPI (CH569) или UHSIF в режиме «ведомый для ПЛИС»
(CH32H417, синхронный FIFO с флагами WRNF/AF#/RDNE/AE#). Выбор между ними — по шагу 0 плана проверки.
